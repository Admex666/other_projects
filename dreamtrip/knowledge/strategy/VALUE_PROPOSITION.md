# 💎 Value Proposition: Total Time Saved / Client

Az Optivoya alapvető értékajánlata a travel advisorok és utazásszervezők számára a kutatási és ajánlatkészítési munkafolyamat radikális lecsökkentése:

> **Fő alapelv:** Nem az API válaszidejét mérjük, hanem a **teljes munkafolyamat során megtakarított időt**.

---

## ⏱️ A Megtakarított Idő Számítása

$$T_{\text{manual}} = \text{teljes manuális research} + \text{összehasonlítás} + \text{shortlist készítés}$$

$$T_{\text{Optivoya}} = \text{Optivoya futtatás} + \text{verification} + \text{editing} + \text{finalization}$$

### 🏆 Fő KPI: Total Time Saved / Client
$$\text{Total Time Saved} = T_{\text{manual}} - T_{\text{Optivoya}}$$

---

## 📊 Másodlagos KPI-k

* **Time Reduction %:** A munkafolyamat időtartamának százalékos csökkenése.
* **Verification Time:** Az az idő, amit az advisor az adatok ellenőrzésével tölt.
* **Edit Time:** Az opciók finomhangolására, cseréjére fordított idő.
* **Shortlist Acceptance Rate:** Milyen arányban fogadja el az advisor a generált shortlistet módosítás nélkül.
* **Advisor Rejection / Edit Rate:** Milyen arányban kell az advisornek elvetnie vagy módosítania az ajánlott elemeket.
* **Factual Error Rate:** Ténybeli, árazási vagy elérhetőségi hibák aránya.
* **Missing Option Rate:** Hiányzó, releváns alternatívák aránya.
* **Time to Client-Ready Proposal:** A kezdő ügyféligénytől a kiküldhető ajánlatig eltelt teljes idő.

> **Összegző tétel:** A valódi érték nem az, hogy az Optivoya milyen gyorsan generál outputot, hanem az, hogy **mennyi idő alatt jut el az advisor egy ügyfélnek elküldhető, megbízható ajánlatig.**
