# Poker EV Tester

Ez a projekt a `LLM_brainstorm.md`-ban leírtak alapján készült, hogy számszerűsíthetővé tegyük a pókerelméleti fejlődésedet.

## Tartalom
- `spots.json`: A teszthelyzetek adatbázisa.
- `tester.py`: Interaktív tesztelő program.
- `analyzer.py`: Statisztikai elemző és vizualizáló eszköz.
- `generate_ev.py`: Példa kód a `pokerkit` könyvtár használatára.

## Használat
1. Futtasd a tesztet: `python tester.py`
2. Nézd meg az eredményeket: `python analyzer.py`

Részletesebb leírást a `README_implementation.md` (vagy az AI által generált artifact) tartalmaz.
